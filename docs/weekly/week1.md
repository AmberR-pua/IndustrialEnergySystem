## 3. 遇到的困难

1. 培训资料含旧框架、Redux 和不同接口包络，与任务书不一致。以任务书为唯一业务依据，不拷贝旧项目，也不混用 code=200/succ 格式。
2. 缺失必须是真正缺行而不是置零；truth 用完整网格独立保留。异常漂移需要逐点标签，同时标明事件；前后保护正常小时，验证下一小时恢复，避免互相覆盖。
3. 当前环境没有 Chromium 可执行文件，不能实际执行浏览器视觉和点击验证。已执行 HTML/静态文件访问、JS 语法、接口与代理错误测试；未生成伪截图。macOS/Windows 未在实体设备实测。
4. 本地开发服务器只面向本机演示，后续如需要生产部署再改部署方案，第一周不扩展范围。
