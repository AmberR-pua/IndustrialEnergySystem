# 接口契约初稿 v0.1

后端 `http://127.0.0.1:8000`，浏览器通过前端 5173 同源代理。所有业务响应：`{"code":0,"message":"success","data":...}`。失败时 code 与 HTTP 状态一致，data 为 null。业务时间为南京 Asia/Shanghai 的本地时间字符串；查询开始与结束均包含边界。

## 第一周已实现

| 方法/路径 | 请求 | 响应 data |
|---|---|---|
| GET /api/health | 无 | service, stage, tables, dataRange, generation |
| GET /api/meta | 无 | areas[], devices[], energyTypes[]，列名采用数据库 snake_case |
| POST /api/raw-data/page | 以下 JSON | total, pageNum, pageSize, list[]（camelCase） |
| GET /openapi.json | 无 | OpenAPI 3.0 文档本体，非业务包络 |
| 算法 GET :8001/health | 无 | service, stage, modelReady=false, trainingImplemented=false |

```json
{"areaId":2,"deviceId":1,"energyType":"ELECTRIC","startTime":"2026-01-01 00:00:00","endTime":"2026-01-01 23:59:59","dataQuality":1,"pageNum":1,"pageSize":20}
```

所有筛选可省略。pageNum 默认 1，pageSize 默认 20（1…200）。未知键返回 400，数值参数必须 JSON 整数而非字符串/bool/小数。areaId 必须存在，包含该区域所有后代；未知 deviceId 得到空列表，便于无数据场景测试。日期不合法或开始晚于结束返回 400。过滤器 AND 连接。

list 项：id, deviceId, deviceCode, deviceName, energyType, dataTime, value, unit, dataQuality, source。缺失不出现在 list 中，不补 0。API 不提供 truth 标签。

本地调试页：`http://127.0.0.1:5173/api.html`。可提交请求查看实际 HTTP 状态与完整 JSON；OpenAPI 文件可导入 Swagger/Apifox。

## 预定接口（第二至四周，尚未实现，访问返回 404）

| 周次 | 方法/路径 | 请求/行为 |
|---|---|---|
| 2 | GET/POST /api/areas；PUT/DELETE /api/areas/{id} | 区域树维护；删除引用冲突 409；环/非法层级 400 |
| 2 | GET/POST /api/devices；PUT/DELETE /api/devices/{id} | 编号、名称、区域、能源、单位、量程 |
| 2 | GET /api/energy-types；PUT /api/energy-types/{code} | 折标与排放因子维护 |
| 2 | POST /api/raw-data/manual | deviceId,dataTime,value；单位从器具获得；重复 409 |
| 2 | POST /api/raw-data/export | 与 page 相同筛选，text/csv，导出所有匹配行 |
| 2 | POST /api/collection/run；GET /api/collection/logs | 回放一个批次、查询采集日志；计划每分钟执行 |
| 2 | POST /api/summary/page | areaId,energyType,periodType,startDate,endDate |
| 2 | GET /api/summary/detail | areaId,energyType,periodType,periodDate；返回组成记录 |
| 2 | POST /api/summary/recalculate | areaId,date；手工补录后重算 |
| 3 | POST /api/predict | deviceId,energyType,granularity,horizon（DAY 时 1…7） |
| 4 | POST /api/anomaly/detect | deviceId,startTime,endTime |
| 4 | GET /api/alerts/page；GET /api/alerts/export | pageNum,pageSize,areaId,level,时间范围 |
| 4 | GET/PUT /api/model/config | modelVersion,threshold,阈值选择依据 |

统计输出 periodDate,totalValue,unit,standardCoal,carbonEmission,expectedCount,actualCount。日期口径：HOUR=`YYYY-MM-DD HH:00:00`，DAY=`YYYY-MM-DD`，MONTH=`YYYY-MM`。不同能源不合并 value。

预测输出 modelVersion,metrics(mape,mae,rmse,r2),history(time,value),forecast(time,value,lower,upper)。mape 单位百分数，mae/rmse 与能源消费量同单位；尚无训练模型时不能返回编造指标。预测区间需记录估算方法，不直接称作经校准置信度。

异常输出 list(dataTime,value,anomalyScore,anomalyType,reason)；缺失 value 为 null。预警输出 total,list(id,areaName,deviceCode,dataTime,anomalyType,level,message)。异常评估明确区分 precision/recall/F1 与总体 accuracy。

算法服务后续约定 POST /train、/predict、/detect，由后端调用而非浏览器直连；第一周只有 health。这份全周期契约是初稿，真实实现前补充分页、错误码、请求/响应 schema 并版本化。
